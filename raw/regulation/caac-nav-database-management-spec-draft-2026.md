# 关于征求《航空运营人机载导航数据库管理规范（征求意见稿）》意见的函

> 来源：中国民用航空局官网（意见征集栏目），2026-07-28 15:21 发布
> 反馈截止：2026年8月14日，邮箱 liyufei@aischina.com（填写附件《修订意见反馈表》）

## 征求意见函原文

为适应当下机载导航数据库的管理和使用需求，进一步完善航空运营人导航数据库管理体系，支持国产导航数据规范应用，筑牢飞行运行安全根基，我司组织修订了《航空运营人机载导航数据库管理规范（征求意见稿）》。

现就该咨询通告征求意见。如有意见建议，请填写附件表格，并于8月14日前发送至邮箱liyufei@aischina.com。

——民航局飞行标准司，2026年7月27日

### 1. 目的

本管理规范旨在向航空运营人提供机载导航数据库管理的依据和规范，同时为局方监察员相关管理工作提供指南。本规范并不是航空运营人机载导航数据库管理的唯一方法，运营人也可采用中国民航局可接受的其他符合性方法。

### 2. 适用范围

本规范适用于CCAR121、135和136部运营人。CCAR91部航空运营人实施基于机载导航数据库的飞行运行时，可参照本规范建立导航数据库管理程序。

本规范中所涉及导航数据库，是指包括航路、进/离场和进近复飞等飞行阶段供航空器使用的机载导航数据库。

### 4. 背景

机载导航数据库是现代大中型运输机飞行管理系统（FMS）及自动飞行控制系统（AFCS）的重要信息源，是现代飞行运行的重要支撑。随着中国民航基于性能的导航（PBN）运行的深入推进，导航数据库已成为保障飞行安全、提升运行效率的核心数据基础。航空运营人作为导航数据库的终端用户，必须从运行应用的角度建立一系列质量管理方法，对导航数据库管理的程序、记录、审计、培训等方面做出规定，从而确保安全、高效地运行。

《航空运营人导航数据库管理规范》（AC-91-FS-2014-21）发布至今，为规范运营人导航数据库管理工作发挥了重要作用。然而，因彼时民航局尚未出台针对航空数据处理及相关数据库的适航审定政策，所以该版咨询通告未明确航空数据供应商的资质要求。

2025年8月，民航局先后发布了《机载航空数据处理及相关数据库》（CTSO-2C611）和《机载航空数据处理及相关数据库符合性指南》（AC-21-AA-2025-43），明确了航空数据供应商为获得中国民航机载航空数据处理及相关数据库批准所必须满足的最低标准和符合性方法。

为此，本次修订旨在将运营人对数据供应商的管理职责与民航局的审定要求相衔接，明确对数据供应商的资质要求，并结合质量管理体系方法对运营人导航数据库管理提出要求，为航空运营人在新的民航发展背景下开展导航数据库管理提供指导。

### 5. 术语（要点）

- **航空数据（Aeronautical Data）：** 支持航空应用的数据，如导航、飞行计划、飞机模拟机、地形感知及其他用途（如导航数据、地形和障碍物数据及机场地图数据）。其他用途还可能包括新兴的航空应用（如动态电子航图等）。
- **航空数据库（Aeronautical Database）：** 以电子形式存储在一个系统中的所有航空数据的总称，包括导航数据库、地形数据库、障碍物数据库和机场地图数据库等。
- **导航数据（Navigation Data）：** 用于航空器位置定义和航径定义的信息，包括但不限于航路点、机场与跑道、航线与终端区飞行程序、导航设施、着陆系统基础设施等，不含地形、障碍物及地理数据。
- **导航数据库（Navigation Database）：** 以电子形式存储在系统中，用于支持导航应用的导航数据集合、打包及格式化文件的总称。内容主要包括航路点、导航设施、航路、机场、仪表飞行程序、公司航路等信息。
- **导航系统数据库规范（ARINC-424）：** 航空业界推荐的机载导航系统参考数据的陈述性文件，定义导航数据库的结构、格式和内容，确保不同航电设备之间的兼容性。
- **航空数据链（Aeronautical Data Chain）：** 航空数据从创建到最终使用过程的概念性表述，通常由五个典型组织机构组成：数据创建方、航空情报服务机构（AIS）或地形数据提供机构、数据提供人、应用集成商（或航电设备制造商）和终端用户。
- **机载航空数据处理及相关数据库CTSOA（数据库CTSOA）：** 民航局颁发的证件，记录数据供应商已满足CTSO-2C611的要求，提供数据库完好性的证据。分为1类CTSOA（确认交付的航空数据库满足民航局要求，不对机载系统兼容性确认）和2类CTSOA（同时确认与特定航空电子系统兼容）。
- **数据供应商（Data Supplier）：** 在航空数据链中负责为用户处理航空数据（包括数据分发）的团体、组织或参与者（不包含缔约国和代表缔约国的实体机构）。
- **数据质量要求（DQR）：** 对航空数据在准确性、分辨率、完好性、可追溯性、时效性、完整性以及格式等方面提出的要求，是数据质量控制的核心依据。
- **航空资料定期颁发制（AIRAC）：** 航空运行活动需要做出重大调整时，按照航空资料共同生效日期提前发布通知的制度。
- **官方数据 / 标准数据（Standard Data）/ 客户化数据（Tailored Data）：** 官方数据为国家或地区航空情报部门提供的航空数据和情报；标准数据为数据供应商按特定规范制作、可供所有运营人使用的数据；客户化数据为运营人按特有需求定制、仅供自身使用的数据。
- **飞行管理系统（FMS）：** 集成了航空器导航管理和性能管理功能的机载计算机管理系统。

### 6. 航空运营人导航数据库质量管理

**6.1 组织机构与职责：** 运营人应设置导航数据库管理机构、配备管理人员及适当的设施设备、数据库管理工具，根据机队规模、运行范围、导航数据库种类及数量合理配置人员。机务部门负责机载导航数据库的装载，飞行、标准、机务、模拟机等职能部门协助。运营人应及时更新导航数据库，并最终负责确保导航数据满足其预期应用的质量要求；建立质量管理程序和规定并纳入手册体系，确保：接收的数据满足数据质量要求、管理程序有效实施、不发生未经授权的偏离、正确实施审计和控制措施。

**6.2 质量管理程序要求，主要包括：**
- **6.2.1 导航数据库数据质量要求：** DQR基于数据应用的预期功能定义。运营人作为最终用户，应确保DQR得到定义且适用于预期用途；从持有中国民航导航数据库2类CTSOA或民航局其他方式同意的数据供应商处获取导航数据库，可在很大程度上满足该要求。运营人对数据质量要求中的完整性要求和时效性要求负有最终责任。运营人若对2类CTSOA供应商提供的数据进行格式化或更改，须按AC-21-AA-2025-43和CTSO-2C611要求获得数据库CTSOA。
- **6.2.2 数据供应商管理：** ⭐**自2027年1月1日起，首次申请适航证的民用航空器，其机载航空数据需已获得中国民航局的批准**；其他民用航空器，除经民航局同意外，原则上数据供应商应持有中国民航导航数据库CTSOA。运营人自行选择符合要求的数据供应商并确认其资质和能力；与供应商建立数据更改、偏离、差错或异常发布及反馈机制；监控供应商资质与交付能力；变更供应商或数据库升级换代时应及时修改《运行手册》。
- **6.2.3 导航数据库软硬件管理：** 掌握运行机队及航电设备配置情况并做好记录（机型种类及数量、FMC软硬件型号版本及对应数据库ID、数据库限制条件），建立限制监控机制防止溢载，定期评估机队及航电能力并优化配置。
- **6.2.4 工作程序管理：** 识别主要工作环节并建立工作程序，明确受控程序清单、修订评估机制、批准方式、生效前变更通知方式。
- **6.2.5 人员能力管理：** 建立人员能力管理规定和能力档案（基础信息、培训记录、岗位授权），全程跟踪动态更新，识别能力缺陷时采取纠正措施并记录。
- **6.2.6 文件管理：** 建立受控文件清单、版本唯一标识、发布前审核批准流程、修订标识、有效版本管控、清晰可读保障、外部文件识别管控、授权访问管控、过期文件归档销毁措施。
- **6.2.7 记录管理：** 规定受控记录类型、填写要求、保存期限、存储媒介、防损坏丢失措施。
- **6.2.8 质量管理内部审计：** 每年开展，两次间隔不超过12个月；由导航数据库管理机构以外的部门（如质量管理部门）组织实施；审计内容至少包括工作程序、人员能力、供应商资质、问题差错异常处理、记录完整有效性；重大变化、保障水平下滑或发生不安全事件时开展事件驱动型审计。
- **6.2.9 管理评审：** 每年开展，间隔不超过12个月；明确负责管理评审的高级管理人员（一般指运行控制部门领导或以上），评估管理体系充分性、适宜性、有效性，保留完整记录。

### 7. 导航数据库工作流程

**7.1 一般工作流程**（周期性）：提交需求 → 接收导航数据库 → 质量检查 → 装载 → 机组使用 → 监控和报告 → 记录。
- 运营人如不具备日常管理能力，可委托其他运营人或第三方，但应向局方申请修订运行规范A0017和（或）相关运行手册，最终责任仍在运营人。
- **质量检查：** 标准数据质量检查可免除（RNP AR程序相关数据除外）；客户化数据每周期至少对变更内容检查（RNP AR除外）；RNP AR程序相关数据每周期进行完整质量检查（按AC-91-FS-05-R2）。数据差错异常应及时联系供应商处理，必要时发布告警信息或公司通告。
- **装载：** 导航数据库管理机构与机务部门建立传递和信息沟通机制，确保在数据周期生效前将正确版本装载到相应机队。
- **机组使用：** 飞行前驾驶舱准备必须确认导航数据库当前有效；AIRAC周期更替时应制定计划识别潜在影响；PBN运行前对照航图检查飞行计划（跑道、程序、航路点顺序、航迹角度、距离、高度速度限制等）；传统飞行程序中数据库仅作辅助手段，以传统导航为准；发现影响飞行安全的问题应记录并及时报告。
- **记录要求：** 各环节工作记录须保存至少1年。

**7.2 特殊工作流程——飞行程序验证导航数据库管理：** 依据AC-97-FS-002R1，机场完成新设计或修订飞行程序后，在局方正式批复前通常需验证（模拟机验证和/或实地验证试飞）。流程包括：编码资料获取（向机场获取飞行程序正式设计预先批准及数据库编码表）、数据供应商选择、验证前导航数据库检查（机场基准点、标高磁差、跑道磁方位长度、入口标高坐标、导航台、航路点、程序代号、航迹走向、航径终止码、航段角度距离、高度速度限制、下滑角等11项）、导航数据库修改（数据严重不符时须立即告知局方/机场/设计单位/供应商并追踪修改；特殊情况下经地区管理局同意方可人工输入导航数据，实地验证试飞仅限目视飞行条件下执行）。验证库可独立管理或与运行库合并，但须防止未经正式批准的导航数据投入实际运行。

### 8. 人员培训

运营人应制定导航数据库管理人员训练大纲并保持现行有效，包括初始培训、定期复训、重新获得资格训练三类；每课程阶段列明训练内容和计划训练小时数；人员必须完成训练并通过检查方可上岗。

- **初始培训：** 基础培训（规章规范解读、航空数据收集整理含AIP/NAIP/NOTAM信息提取、航图知识、传统及现代导航基础、传统及PBN程序基础、ARINC-424、数据质量控制方法、航图与数据库关系、管理工具使用、FMS原理及功能、模拟机控制显示组件操作）+ 在职培训（OJT，公司手册和业务流程）。
- **定期复训：** 每2个自然年开展1次，间隔不超过30个月，内容含基础培训适当科目及相关规章规范手册变更。
- **重新获得资格训练：** 未按期复训丧失资格36个月（含）以内按复训要求执行；连续12个月以上未从事该工作的含适当在职培训；丧失资格36个月以上须完成初始培训全部科目。

### 9. 运行监督和检查

局方对运营人导航数据库质量管理工作的监督检查内容（11项）：管理政策及要求、管理机构设置、管理人员配置及能力、培训记录、数据质量要求、数据供应商管理、软硬件管理、质量审计记录、工作记录、对受委托方的管理、其他程序文件或记录。

### 10. 生效与废止

本通告自下发之日起实施。咨询通告《航空运营人导航数据库管理规范》（AC-91-FS-2014-21）同时废止。

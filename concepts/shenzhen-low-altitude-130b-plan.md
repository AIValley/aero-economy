# 深圳低空经济1300亿方案：《低空基础设施高质量建设方案（2024—2026年）》

> 深圳市发展和改革委员会 2025-07-31 发布（中新社报道）；入库日期 2026-08-03
> 来源：raw/web/20250731-shenzhen-low-altitude-130b-plan.md
> ⚠️ 口径澄清：**1300亿 = 2026年底低空经济产值规模突破1300亿元**，并非"总投资约1300亿元"。总投资规模方案未公布。

## 一、方案定位

《深圳市低空基础设施高质量建设方案（2024—2026年）》是深圳为落实"全球低空经济第一城"目标出台的**低空基础设施建设专项方案**，围绕构建"体系完备、层次清晰、标准统一、智能先进、跨域融合"的低空基础设施体系展开，以基建牵引产业。

**关键日期与时效：** 方案2025-07-31发布，执行期2024-2026年。2026年7月深圳又印发《深圳市低空航空器起降设施布局规划（2026-2035年）》（超1500个起降点），属后续递进规划而非对本方案的替代（见 vault raw/wechat/深圳规划布局超1500个起降点-低空经济观察.md）。

## 二、四大中心与量化目标（2026年底）

| 中心 | 量化目标 |
|------|----------|
| **全球总部研发中心** | "1+5+4"布局：1个低空经济大科学装置、5个低空经济运行试验区、4个测试场；一批全球领军低空研发制造企业；**产值规模突破1300亿元** |
| **高端智造中心** | 10个低空经济产业园区+2个特色产业园区；飞控算法/高能量密度电池/低功耗主控芯片/高性能轻量化材料/复杂环境感知等关键核心技术重大突破；产业链核心技术与关键零部件**自主可控** |
| **全场景示范验证中心** | 起降点1200个以上；商业航线1000条以上；直升机/eVTOL起降设施1公里半径覆盖建成区面积比突破50%；"2小时同城、4小时跨城"低空快送覆盖人口超70%；三甲医院/血液中心覆盖超50%；城市治理起降场3公里半径覆盖全市公园/河道/水库/岸线巡检；载人飞行、物流、观光、航空运动、电力巡线、港口巡检、航拍测绘、农林植保商业化应用 |
| **一站式解决方案供给中心** | 建成**全球首个低空智能融合系统（SILAS）**；低空通信、导航、监视、气象监测服务保障全覆盖；低空算力平台投入使用；形成可复制可推广的一站式解决方案 |

## 三、四大重点任务与起降设施分项

四大重点任务：①构建低空起降基础设施 ②建设低空信息基础设施 ③布局低空创新基础设施 ④强化标准化服务能力。

**起降设施分项目标（2026年底）：**

| 类别 | 新建 | 总规模 |
|------|------|--------|
| 直升机/载人eVTOL起降场（点） | 174个 | 283个 |
| 物流运输起降点 | 159个 | 205个 |
| 社区配送起降点 | 339个 | 413个 |
| 医疗物资运输起降点 | 112个 | 148个 |
| 商圈配送起降点 | 227个 | 265个 |
| 城市治理无人机起降点 | 340+个 | 360个 |
| **合计** | — | **1200个以上** |

**关键节点：** 2026年底前投用龙华樟坑径直升机场、完成南头直升机场搬迁；深汕通用机场力争2026年底稳定场址；建成深圳低空运营总部基地+龙华樟坑径全场景示范中心；盐田区通航保障基地一期扩展；蛇口邮轮母港、深业上城、后海中心、东湖公园、梧桐山、光明科学城、坝光片区、河套等新建低空应用示范点。2025年底：三维多物理场耦合风洞设施先导装置投用。

## 四、对行业的信号意义

1. **城市级基建先行成为主线** — 方案是纯基建专项（起降设施+信息设施+创新设施+标准），印证"低空经济竞争本质是基础设施竞争"的判断；与 [[low-altitude-vertiport-three-tier-network]] 的枢纽-节点-末梢三级网络互相印证。
2. **产值目标量化到"亿"级** — 1300亿元产值是深圳首个明确的低空经济总量目标，为产业链企业提供可锚定的市场空间预期（2026年底）。
3. **SILAS = 低空数字底座信号** — 全球首个低空智能融合系统作为国家试验区核心抓手，通信/导航/监视/气象全覆盖，直接利好空管信息化、低空数字化服务商。
4. **eVTOL商业化时间表** — 起降设施1公里半径覆盖建成区50%+，为载人eVTOL城市运营铺设物理前提；与 [[low-altitude-civil-aviation-law-countdown]]（2026.7.1新民航法施行）形成"法规+基建"双轮。
5. **产业链自主可控** — 飞控、电池、芯片、轻量化材料、感知五大关键技术列为突破重点，指向国产供应链投资机会。
6. **深圳范式可复制** — "四大中心+量化指标+分项设施清单"的编制方法可被其他城市参照，深圳继续充当全国低空经济政策样板（继 [[guangdong-low-altitude-policy]] 之后）。

## 五、与已有概念的对话

### [[low-altitude-weekly-2026-07-27-08-02]]
周报记录2026年7月底政治局将低空经济列入"六大新兴支柱产业"——深圳1300亿方案（2025年发布）正是支柱产业定位在**城市执行层**的落地样本；两者合看：顶层定调（支柱产业）→ 城市量化落地（1300亿产值/1200起降点）→ 时间表2026年底。

### [[low-altitude-2026-policy-landscape]]
2026政策变局全景（扫码飞全国、12城UAM、湖南全域空域放开等）中，深圳方案代表**特大城市基建先行路线**，与全国性空域/数据政策形成"城市设施+国家制度"互补。

### [[low-altitude-vertiport-three-tier-network]]
深圳2026年底1200个起降点目标与其后2026-2035年超1500个起降点布局规划一脉相承；三级网络概念页以深圳为范本案例，本方案提供其前序量化版本（2024-2026）。

### [[guangdong-low-altitude-policy]]
广东省层面政策（七大突破）与深圳市层面基建方案的纵向关系：省级定方向、市级出设施清单。

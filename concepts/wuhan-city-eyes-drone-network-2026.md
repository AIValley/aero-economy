# 武汉"城市智眼"——超大城市低空治理的"基础设施级"样本

> 全国首个实现超大城市全域覆盖的低空无人机遥感监测网络。2024年8月上线，146座无人值守机场、累计飞行47万公里、服务16个部门。它的意义不在"机场多"，而在"一套系统、多部门共享"——把无人机从"部门各自采购的工具"变成了"城市级公共基础设施"。

## 一、核心事实与规模数据

| 指标 | 数据 |
|------|------|
| 定位 | 全国首个超大城市全域低空无人机遥感监测网络 |
| 研发/运营主体 | 武汉市测绘研究院（统一建设、统一运维） |
| 上线时间 | 2024年8月 |
| 无人值守机场 | 146座（全城146个点位同步作业） |
| 布局半径 | 中心城区2-3公里、开发区和新城区4-5公里 |
| 到达时效 | 除禁飞区外，5分钟内到达全市任一地点 |
| 累计飞行 | 超47万公里 |
| 作业时间 | 1.5万小时 |
| 服务部门 | 16个（公安交管、城管、环保、园林、应急等） |
| 架构 | "1+1+1+N"：1个低空无人机监测网+1个云控平台+1套AI算法库+N个应用场景 |

## 二、技术架构：从"飞起来"到"看得懂"

- **首创"高精度低空空域时空信息格网"**：解决超大城市低空"底图"问题——空域被格网化后，系统可做机场智能调度、航线智能生成、障碍智能规避，实现"一键直飞、接力续飞、临时转飞"
- **"三端"AI算力**：飞机端+边缘端+云端；内置几十类城市治理AI算子（如自动标记未戴安全帽的施工人员）
- **数据产品**：飞行完成后快速生成城市实景三维模型，城市巡查从"人眼判"跃升为"智眼识"
- **接入"一网统管"**：全市无人机全部接入城市运行"一网统管"平台，成为城市"神经网络"的空中感知触角，重大活动（武汉马拉松、渡江节）、节日保障、应急处置可直接调用

## 三、"一套系统+多部门共享"模式（核心范式）

- **传统模式痛点**：部门各自为政——交管买一批、环保买一批、城管买一批 → 设备重复、数据孤岛、运维成本高
- **武汉做法**：146台机场由测绘研究院统一建设运维，16个部门通过统一云控平台按需调用 → "一平台，多场景，全覆盖"
- **本质**：把低空感知能力做成**城市公共品/基础设施**，类似"电网"而非"每家自备发电机"。这是超大城市低空治理的范式创新——**所有权与使用权分离**（研究院持有资产，部门按需租用服务）

## 四、落地成效：三个可量化的场景

1. **公安交管（武昌区）**：辖区日均车流量90万架次；无人机自2025年8月部署以来累计处置**400起高架交通事故**，其中约30%通过**远程喊话**引导车主自行处理、无需民警上桥——破解固定高点监控盲区多、电子眼易被规避、高架事故警力难达三大痛点
2. **森林防火**：过去一年616次无人机自动巡飞、181架次核查火情；"30分钟闭环"核查机制；监测频次从季度级提升至**日级**，图斑识别精度达**亚米级**
3. **城市治理日常**：AI自动识别未戴安全帽施工人员等场景；多部门按需调用，一个平台支撑交管/环保/城管/园林/应急

## 五、G端场景 = 低空经济"赚钱第一战场"（行业判断）

文章给出的行业证据链：

- 民航局《2025年民航行业发展统计公报》：全国注册无人机328.7万架、全年飞行4530.29万小时（同比+70%）
- 农用无人机保有量超30万架、作业面积超30亿亩次（截至2025年11月底）
- 大疆《低空经济基础设施发展白皮书（2026）》：自动机场产品覆盖全球80+国家、累计超800万飞行架次/200万飞行小时——**大部分来自电力巡检、城市治理、交通巡查、自然资源监管等B端/G端场景**
- 2026年7月上海低空经济博览会：452家企业570架航空器，**实现商业化落地的大多集中在政府公共服务与行业生产领域**
- 反面对照：消费端无人机配送受限于空域审批、单均成本；载人eVTOL受困于适航取证、起降充电设施、空管体系、运营成本

**结论**：产业正从"研发制造"主导向"场景落地"加速切换，而**第一波赚钱的场景在G端（政府公共服务）与B端（行业生产）**——政府买单的确定性（"一网统管"是入口）、客单价与稳定性远高于C端。武汉这类城市级低空基建网络 + 跑通的政务场景，是万亿市场"最扎实的底座"，同时为未来低空物流、空中交通积累空域数据、运营经验与公众认知。

## 六、对从业者的意义

1. **做产品/运营**：单城146座机场、16个部门共享——低空感知网络的规模效应与复用价值是核心卖点；"1+1+1+N"架构（网+平台+算法库+场景）是可复制的产品化框架，武汉是样板
2. **做政府业务**：G端是当前现金流最确定的战场；"所有权与使用权分离"（政府/城投持资产、部门按需调用）是值得借鉴的商业模式设计；"一网统管"接入是打通政府买单的关键入口
3. **做技术**：低空空域时空信息格网（空域底图）、机场智能调度/航线生成/障碍规避、三端AI算力、实景三维快速生成——这些是城市级低空基建的硬技术栈，也是其他城市复制的门槛
4. **投资视角**：验证"G端先行、场景落地"节奏；关注低空感知/巡检/城市治理赛道的常态化运营（非试点）信号；警惕只讲故事无常态化运营数据的企业
5. **政策配套**：工信部等五部门要求2027年全国低空公共航路地面移动通信网络覆盖率≥90%——低空感知网络将获得"国字头"基础设施支撑，城市级无人机网络的复制窗口正在打开

# 最高人民法院商业特许经营典型案例（2026-08-12）

> **来源：** 最高人民法院新闻局官方发布（2026-08-12 10:12），一手源 `raw/policy/20260812-spc-franchise-typical-cases.md`

> **入库日期：** 2026-08-13
> **性质：** 官方典型案例全文（7件，含基本案情/裁判结果/典型意义/案号）——本页为**一手源档案层**；对低空经济业务的分析解读见 [[franchise-typical-cases-low-altitude-lessons]]（分析层）

## 发布背景

2026年8月12日，最高人民法院发布 **7件商业特许经营典型案例**。商业特许经营俗称"加盟连锁"，指拥有注册商标、企业标志、专利、专有技术等经营资源的企业（特许人），以合同形式将其经营资源许可其他经营者（被特许人）使用，被特许人在统一经营模式下开展经营并支付费用的经营活动，常见于餐饮、零售、酒店、教育培训、快递物流、美容美发等民生领域。发布背景：特许人夸大宣传、盲目扩张，被特许人忽视风险、跟风投资等问题一定程度存在，矛盾纠纷日益增多。

官方归纳的 **4 大特点**（发布通稿原文）：

| 特点 | 对应案例 | 要旨 |
|---|---|---|
| 一是准确认定特许经营法律关系 | 案例一 | 穿透合同外在形式，整体认定特许经营合同关系 |
| 二是依法保障被特许人合法权益 | 案例二、案例五 | "冷静期"单方解除权属法定权利；备案资格被撤销后支持解除合同 |
| 三是督促特许人全面履行法定义务 | 案例三、案例四 | 非企业主体合同无效；虚假宣传构成欺诈、撤销合同 |
| 四是严厉打击特许经营领域违法犯罪行为 | 案例六、案例七 | 行政处罚合法性获司法确认；借用加盟外壳实施合同诈骗定罪 |

|---|---|---|---|
| 案例一 | 杨某与某公司特许经营合同纠纷案 | **合同性质实质性认定**：签多份合同但共同体现特许经营特征（许可经营资源+统一经营模式+支付对价）的，整体认定特许经营法律关系；合同拆分/名称包装不能规避《商业特许经营管理条例》适用 | （2020）京0106民初24944号 / （2021）京73民终1296号 |

| 案例四 | 张某、王某与某公司特许经营合同纠纷案 | **虚假宣传构成欺诈**：编造经营收益数据（如"一天流水3万多"）虚假宣传、无证据支撑，使被特许人错误判断签约 → 构成欺诈，合同可撤销；特许人担主要责任 | （2019）川01民初6406号 / （2020）川知民终405号 |
| 案例五 | 岑某与某公司特许经营合同纠纷案 | **履约能力动态审查**：履约期间备案资格被撤销、涉诉多起无财产可供执行 → 履约能力弱化构成违约；合同解除+费用部分返还；确立动态履约能力审查裁判路径 | （2023）浙8601民初706号（一审生效） |

### 逐案要点（官方原文提炼）

**案例一（杨某案）——合同定性穿透。** 2019年11月28日杨某与某公司同日签订《服务协议书》《项目标识使用协议》并支付培训服务费15万元，公司辩称系"技术服务及品牌标识使用许可"非特许经营。法院认定：从合同目的看两协议具有统一目的（指导使用其经营资源开展某餐饮项目经营）；从合同内容看服务及标识均系其可授权使用的经营资源，杨某按统一经营模式经营并支付对价 → 构成统一的特许经营合同关系。公司根本违约，判决解除合同、返还15万元并支付违约金7000元。**裁判规则：** 特许经营三特征 = ①特许人拥有注册商标/企业标志等经营资源；②被特许人按授权在特定经营模式下使用；③被特许人支付特许经营费用。数份合同共同体现上述特征即从整体上认定为特许经营法律关系。

**案例二（刘某、雷某案）——冷静期法定权利。** 2019年6月26日签《品牌拓展合同》加盟杭州餐饮项目、付3.5万元；公司仅提供《技术手册》未提供实际培训指导；刘某雷某未开店、未利用经营资源，签约后第15天提出退款。法院：条例第12条赋予的"冷静期"单方解除权目的在于缓冲投资冲动；合同未约定解除权和解约期限时特许人具有缔约过失；**合理期限有约定从约定、无约定结合行业特点与商业惯例确定，一般不宜过长，通常以被特许人未实际利用经营资源为限**；合同第四条"领取培训资料便不能要求返还"系格式条款，公司未举证已提请注意，内容明显不合理限制被特许人权利、免除减轻特许人责任 → 无效。判决确认合同解除、返还3.5万元。

**案例三（汤某案）——非企业主体合同无效。** 某俱乐部系个体工商户（武术/散打/搏击/跆拳道培训），2023年8月与汤某签《加盟合作协议》（20年期限、加盟费3万、品牌使用费每年5000元）。法院：协议符合特许经营基本特征；条例第3条第2款"企业以外的其他单位和个人不得作为特许人"属强制性规定，个体工商户不符合特许人主体要件 → 合同无效；考虑俱乐部已提供装修方案并派教练指导，结合双方过错酌情返还1.5万元。

**案例四（张某、王某案）——编造经营数据构成欺诈。** 2018年6月28日签《餐饮业服务合同》，支付服务费86800元、代购料款44900元、装修55000元；公司招商广告中创业者宣称"一天流水3万多""最少能卖七、八百份"。四川高院：特许人掌握品牌、经营资源等全部信息，被特许人处于明显弱势；招商广告含收益内容但公司未提交报表、票据等证据 → 故意发布虚假信息使被特许人错误判断、违背真实意思签约，构成欺诈，合同撤销；公司担主要责任、张某王某担次要责任（未充分考虑商业风险草率签约），公司返还服务费2万元并赔偿经济损失3.5万元。

**案例五（岑某案）——履约能力下降可解除合同。** 2020年11月12日签《特许加盟合同书》（3年、加盟费15.9万元+保证金1万元），公司签约前已完成备案，但履行中因违反条例被行政处罚、2022年10月24日因不满足"拥有成熟的经营模式"法定要求被撤销备案资格，且涉诉多起、多起执行案件暂无可供执行财产线索。法院：特许人对经营体系重大变化及对被特许人有重大影响的信息（资质变更/撤销）负有披露义务，公司未披露且履约能力受限构成违约；岑某未积极选址亦有违约；综合双方过错判决解除合同、返还7万元。

**案例六（某公司行政处罚案）——"两店一年"与备案。** 2021年9月23日福州市商务局检查发现某公司未备案开展特许经营；责令2021年10月31日前完成备案；10月8日申请备案因门店不符合要求未被受理；2022年1月28日以"不具备特许经营条件"违反条例第7条第2款为由罚款10万元。法院：某公司提交的15家门店均为个体工商户而非其直营（部分为股东但均未绝对控股），依商务部直营店认定标准均无法认定为直营店 → 不满足"2个直营店且经营超1年"；商务局罚款10万元并无不当。条例第7条第1款的"成熟经营模式+持续提供经营指导/技术支持/业务培训能力"由第2款"两店一年"具象化。

**案例七（叶某等合同诈骗案）——借加盟外壳实施刑事诈骗。** 叶某、谭某实际控制某甲公司，指使他人担任法定代表人/股东，购买"蜜桃里"商标注册至公司名下；明知无特许经营资质、资源及成熟经营模式，委托某乙公司短期快速招商（加盟费按22:78分成），招商人员虚构品牌与知名品牌同集团/合作关系、诱骗被害人至直营店考察，派驻的石某、乔某及商务团队贴靠知名品牌、虚增经营业绩、购买知名品牌产品冒充自有产品诱骗签约；之后消极履约、放任经营失败；截至案发骗取300余名被害人加盟费共计5400余万元；二人此前从事类似商业模式产生大量纠纷、短期内频繁更换品牌继续招商。法院：**非法占有目的认定**遵从主客观相一致原则，从①有无实际履行能力、②是否采用欺骗方式诱骗签约、③是否实际履行合同、④是否转移隐匿财产等方面评判；四被告人均明知套路并积极参与 → 合同诈骗罪，判处有期徒刑十二年至五年并处罚金。

## 对低空经济等新业态的启示

7件案例虽直接针对餐饮、零售、教育培训等传统民生领域，但裁判规则具有普遍适用价值。低空经济正处于"风口概念"向"产业现实"转型期，无人机培训、低空旅游、物流配送等赛道加盟模式快速兴起（主文章引行业数据：2025年中国低空经济市场规模已突破8000亿元），同时面临资质参差不齐、夸大宣传、履约能力不足等突出问题：

| 案例裁判规则 | 低空经济场景映射 |
|---|---|
| 合同定性穿透（案例一） | 低空项目将特许经营拆分为《技术服务协议》《设备采购协议》《品牌使用协议》或包装为"城市合伙人/区域代理/战略合作"协议，不能规避条例适用 |
| 冷静期（案例二） | 风口行业"零基础入行""月入十万"宣传促使仓促签约；未接受培训/未采购设备/未招生即处于可行使解除权状态 |
| 主体资格（案例三） | 个人"飞行教练""无人机达人"以个人品牌招加盟属无资质特许人，合同无效；低空特许人还应具备行业特殊资质（CAAC训练机构资质/通用航空经营许可证/维修资质认证） |
| 虚假宣传（案例四） | "年培训学员超5000人""就业率95%""单店年净利180万"等无数据支撑的宣传构成欺诈；虚构与外卖平台/物流企业战略合作、伪造eVTOL订单 |
| 履约能力（案例五） | CAAC训练机构资质被暂停/撤销、通航经营许可证被吊销 → 特许人应主动披露、被特许人应建立资质动态监控 |
| 两店一年+备案（案例六） | "两店一年"须实质理解（直营培训点/直营起降场地与飞行器，挂名合作不算）；未备案可被行政处罚（案例中罚款10万元）；被特许人可通过商务部特许经营信息管理系统查询备案 |
| 刑事诈骗（案例七） | "eVTOL城市合伙人""低空物流区域代理"骗局：无资质无资源却宣称"核心技术/独家空域资源"、短期快速招募收取高额加盟费后消极履约、频繁换品牌继续招商 → 合同诈骗罪 |
